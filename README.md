# 🌍 Barcelona Trip Itinerary - 15-18 Julho 2026

Um website interativo e responsivo com o itinerário completo de viagem para Barcelona.

## 📋 Informações da Viagem

- **Período:** 15-18 de Julho 2026
- **Duração:** 4 dias (3 noites)
- **Ida:** Porto → Barcelona (Terça, 07:15 → 10:00)
- **Volta:** Barcelona → Porto (Sábado, 20:40 → 21:40)

- 🎮 INOKO - Experiência VR (€18)
- 🏖️ Praia de Bogatell
- 🍷 Jantar e copos à noite

### Quinta, 16 Julho - Praia e Futebol
- 🏖️ Manhã na praia
- ⚽ Camp Nou - Tour do estádio (€29)
- 🏊 Tarde na praia com mergulho
- 🍽️ Refeições económicas

### Sexta, 17 Julho - Cultura e Gastronomia
- 🏪 Mercado La Boqueria
- 🌳 Parque Güell (€16)

- 🏊 Última manhã na praia
- 🛍️ Exploração do centro
- ✈️ Partida para Porto (20:40)

## 🖥️ Como Usar

1. **Abrir no navegador:** Duplo clique no `index.html`
2. **Navegar:** Use o menu superior ou scroll

4. **Imprimir:** Ctrl+P (ou usa o botão de print do navegador)
5. **Exportar:** Ctrl+E para descarregar CSV
